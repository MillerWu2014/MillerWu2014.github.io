创建`RDD`主要有三种方式：从外部数据创建`RDD`，从另外一个`RDD`创建，对现有的数据列表或者数据集合进行创建。三种方式均能够创建`RDD`对象。`RDD`可以包含`Scala`，`Python`，`Java`的任意类型的对象，因此任何数据均可以创建`RDD`。`spark`创建`RDD`时首先需要通过`SpakContext`作为对象，创建一个`sc`对象，再通过`sc`来创建`RDD`。`sc`对象之前可以通过`sparkconf`对象对`SpakContex`t进行设置。如集群的`URL`和应用名等等。下面是对`SpakContext`对象设置。如下：
```python
from pyspark import SparkContext, SparkConf

conf = SparkConf().setAppName("test").setMaster("local").setSparkHome("/opt/spark1.6.0/")
sc = SparkContext(conf=conf)
```
上面通过`SparkConf`对象设置了`conf`. 再创建`sc`对象，并将设置传给`sc`对象。`SparkConf`对象的方法有：`set(key,value),setIfMissing(key,value),setMaster(value),setAppName(value)，setSparkHome(value)，setExecutorEnv(key=None, value=None, pairs=None)，setAll(pairs)`并对应了`get`方法。

- **外部数据创建RDD**

`spark`提供很多外部数据创建的接口，如下面所示的`textFile`.还有`hadoopFile`,`pickleFile`以及`sqlContext.jsonFile`，还提供`sql`以及`hadoop`的接口。基本包含了主要的数据格式的读入接口。下面是通过`textFile`对文本数据进行创建`RDD`。
```python
from pyspark import SparkContext
from pyspark.mllib import classification
from pyspark.mllib.regression import LabeledPoint
from pyspark.mllib.evaluation import BinaryClassificationMetrics

logFile = "/opt/spark1.6.0/data/mllib/sample_svm_data.txt"
sc = SparkContext("local", "Simple App")
logData = sc.textFile(logFile)
sc.stop()
```
- **从集合数据中创建RDD**

比如从`Python`的`array`中创建`RDD`。这种创建方式为最简单的一种方式。直接通过`SpakContext`的`paralleliza()`方法即可。这种方法可以快速的创建`RDD`对象，再对`RDD`对象进行转化操作及行动操作等等。下面例子中就是通过`paralleliza`方法创建`RDD`。
```python
#!/usr/bin/env python
# _*_ coding:utf8 _*_
from sklearn.datasets import load_iris
from pyspark import SparkContext, SparkConf

conf = SparkConf().setAppName("test").setMaster("local").setSparkHome("/opt/spark1.6.0/")
sc = SparkContext(conf=conf)
data_set = load_iris()
data = data_set["data"]
spark_data = sc.parallelize(data)
print spark_data.collect()
sc.stop()
```

在`spark`中也提供了`dataframe`类型的接口。可以创建`dataframe`,和`pandas`下的`dataframe`非常相似，并且有很多相同的操作。创建的方式有很多，可以从数据库中创建，如`mysql，hive，hdfs，json`等等。下面是各个接口创建`dataframe`的例子。
```python

users = sqlContext.table("users")

logs = sqlContext.load("s3n://path/to/data.json", "json")
# 加载HDFS上的Parquet文件
clicks = sqlContext.load("hdfs://path/to/data.parquet", "parquet")
# 通过JDBC访问MySQL
comments = sqlContext.jdbc("jdbc:mysql://localhost/comments", "user")
# 将普通RDD转变为DataFrame
rdd = sparkContext.textFile("article.txt") \
                  .flatMap(lambda line: line.split()) \

wordCounts = sqlContext.createDataFrame(rdd, ["word", "count"])

# 将本地数据容器转变为DataFrame
data = [("Alice", 21), ("Bob", 24)]
people = sqlContext.createDataFrame(data, ["name", "age"])

# 完整的例子
#!/usr/bin/env python
# _*_ coding:utf-8 _*_
from sklearn.datasets import load_iris
from pyspark import SparkContext, SparkConf, SQLContext
import pandas as pd

conf = SparkConf().setAppName("test").setMaster("local").setSparkHome("/opt/spark-1.6.0/")
sc = SparkContext(conf=conf)
data_set = load_iris()
data = data_set["data"]
df = pd.DataFrame(data=data)
s_data = SQLContext(sc).createDataFrame(df)
print s_data.count()
print s_data.schema, s_data.columns
sc.stop()
```
